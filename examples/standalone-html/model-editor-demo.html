El sistema detecta solo cómo se unen tus tablas (claves foráneas). Aquí las ves, las confirmas o ajustas, marcas la tabla de hechos (★) y exportas el modelo que permite preguntar cruzando tablas, sin fórmulas. Arrastra las tablas; clic en una columna y luego en otra para crear una relación; ✕ para quitarla.
